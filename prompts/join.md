## 1. 회원가입 페이지 만들기
- 회원가입 페이지를 만들자.

## 2. 디자인
- Pencil mcp 를 이용
- SignUp Page 를 구현
- 공통헤더가 있도록 구현


## 3. 구현
- 우선 Pencil 에서 Signup Page 컴포넌트를 참고하여 UI 만 구현한다.
- Join.jsx 파일을 생성 후 구현
- 로그인페이지에서 회원가입을 누르면 회원가입 페이지로 이동.


## 4. 기능

### 4. 1 주소 검색
- 주소검색은다음 운편번호 서비스 api를 이용하여 만든다.
    필요한 라이브러리는 설치할 것 
- 주소를 검색 한 후 선택하면 주소 input 창에 입력되도록 한다.

### 4.2 패스워드 확인
- 패스워드는 패스워드 확인과 입력 값이 일치해야한다.
- 실시간으로 비교해서 결과를 보여준다.
- 패스워드와 패스워드 확인이 일치해야 회원가입이 가능하다.

### 4.3 필수값 처리
- 상세 주소를 제외하고 모두 필수 값
- 유효성 체크를 통해서 입력되지 않거나 유효값이 입력되지 않은 경우
    입력창 하단에 유효성 체크 처리

## 5. api를 이용한 기능 구현
- api 도메인 : https:sell-books.shop

### 5.1 아이디 중복체크
- endpiont : /api/v1/users/check-id
- method : GET방식
- parameter: userId='admin'

### 5.2 회원가입
- endpiont : /api/v1/users/signup
- method : POST
- data 양식
```

{
    "userId"(필수)  : "admin",
    "email"(필수)   : "aaa@naver.com",
    "passwd"(필수)  : "1234",
    "name"(필수)    : "홍길동",
    "gender"(필수)  : "남자",
    "birthDate"(필수) : "1990-01-01",
    "phone"(필수)   : "010-3333-4444",
    "postalCode"(필수) : "03434",
    "address"(필수) :    "서울시 마포구 서강로",
    "addressDetail" : "꿈마을아파트 110동 1101호"
}
```

### 5.3 구현 유의사항
- 아이디 중복체를 하지 않으면 경고창 출력 회원가입 불가
- 아이디 중복체크 후 아이디를 변경하여 입력하면 중복체크를 다시 하도록 한다.
- 회원가입 성공/실패를 출력하고, 성공하면 로그인 페이지로 이동한다.
