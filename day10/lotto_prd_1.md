## 1. 목표

| 기능 | 설명 |
|------|------|
| 수동 선택 | 번호판(1~45)에서 직접 클릭해 번호 선택 |
| 제외 번호 | 선택한 번호를 랜덤 풀에서 완전 제외 |
| 추천 번호 | 클릭 시 선택 번호에 자동 추가 |
| 반자동 생성 | 선택 번호 유지 + 나머지 랜덤 채움 |
| 색상 구분 | 직접선택(파랑) / 추천(보라) / 랜덤(회색) |

## 3. 기능 명세

### 번호판 상태 (3가지, 상호 배타적)
- **기본** → 흰 배경 / **선택** → 파란 배경 / **제외** → 빨간 X 반투명

### 반자동 생성 로직
```
선택 0개 → 6개 전부 랜덤
선택 1~5개 → 선택 고정 + 나머지 랜덤 채움
선택 6개 → 그대로 출력
※ 제외 번호는 랜덤 풀에서 완전 제외
```

### 제약 조건
- 선택 최대 6개 / 제외 최대 39개 (풀 최소 6개 보장)
- 선택↔제외 동시 불가 / 중복 세트 생성 방지

## 5. 핵심 함수

```javascript
toggleSelect(num)       // 번호 선택/해제
toggleExclude(num)      // 제외 추가/제거
addRecommended(num)     // 추천 → 선택에 추가
generate()              // 반자동 생성 (선택 고정 + 랜덤 채움)
render()                // 전체 UI 다시 그리기
clearAll()              // 초기화
```
